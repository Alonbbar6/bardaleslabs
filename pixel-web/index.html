Six AI agents turn a product idea into a build brief. Every step they take shows up here in real time: who is working, what they are working on, and what gets handed to whom.

      What you are looking at

      Intake

      reads your description and asks what is missing.

      Designer

      writes the spec and picks an approach.

      Parts Buyer

      lists every part, with prices and sources.

      Critic

      checks the design and flags problems.

      Reviser

      fixes what the Critic found.

      Report Writer

      turns everything into a build guide.

      When an agent carries a box to another desk, that is a real hand-off: its output became the next agent's input. A ! on the box means issues were found; ? at the round table means the run is waiting on you.

      Put this in your product

      The office is a drop-in component. Point it at your own event stream and your agents appear at the desks.

      1 · iframe (no code)

      <iframe
  src="/embed.html?ws=wss://YOUR-BACKEND/agents"
  width="100%" height="560" style="border:0;border-radius:12px"
  allow="fullscreen"></iframe>

      Leave ws off to show the demo run. Add &controls=0 to lock the camera.

      2 · npm (your own page)

      npm i @bardaleslabs/pixel-office three

import { createOffice, connectWebSocket }
  from "@bardaleslabs/pixel-office";

const office = createOffice(el, { modelsBase: "/models/" });
connectWebSocket(office, "wss://YOUR-BACKEND/agents");

// or drive it yourself
office.dispatch({ type: "agent.state", agent: "designer",
                  state: "typing", message: "writing the spec" });

      Event schema

      { "type": "agent.state", "agent": "intake",  "state": "typing",  "message": "reading the brief" }
{ "type": "agent.state", "agent": "intake",  "state": "carry",   "to": "designer" }          // to: agent id | "review"
{ "type": "agent.state", "agent": "critic",  "state": "carry",   "to": "reviser", "warn": true }
{ "type": "agent.state", "agent": "critic",  "state": "waiting" }
{ "type": "agent.state", "agent": "report-writer", "state": "done" }                          // states: idle typing carry walk waiting done failed
{ "type": "run.log",     "message": "Run 42 started" }
{ "type": "run.reset" }

      Agents, names and models are configurable (agents: [{ id, name, model }]). Full docs in the README.
