Alternative styles

Same six characters and states as preview.html (style A, flat front-view). All art is original, generated from pixel/voxel data in this file.

Style B — Isometric voxel ("3D")

Every object is built from shaded unit cubes in a 2:1 isometric projection. Handoff walks happen along the floor diagonal; the office can be rotated or extended later because it is real 3D data.

Style C — 3/4 top-down, shaded

RPG-style camera: taller 16×24 characters with two-tone shading, visible desk tops, wall with depth. Closest to the Pixel Agents look, without using any of their assets.
